# Tài liệu Lingozi

| Thư mục | Mục đích |
| --- | --- |
| [project](project/README.md) | Trạng thái hiện tại, nhật ký từng phiên và cách tiếp tục dự án |
| [product](product/README.md) | Tầm nhìn, phạm vi MVP, PRD, roadmap |
| [research](research/README.md) | Nghiên cứu người học và đối thủ |
| [features](features/README.md) | Hồ sơ yêu cầu, đặc tả, thiết kế và kiểm thử từng tính năng |
| [architecture](architecture/README.md) | Kiến trúc, dữ liệu, API và triển khai |
| [decisions](decisions/README.md) | Quyết định kỹ thuật và lý do |
| [guides](guides/README.md) | Hướng dẫn sử dụng công cụ và phát triển |

Luồng đề xuất: nghiên cứu → PRD và phạm vi MVP → yêu cầu/đặc tả từng tính năng → thiết kế và AC → triển khai → kiểm thử. Cập nhật tài liệu khi yêu cầu thay đổi.

Tài liệu ghi trạng thái `draft`, `in-review` hoặc `approved`, người phụ trách và ngày cập nhật. Chỉ đánh dấu `approved` khi có xác nhận thực tế. Chưa có tính năng hoặc yêu cầu sản phẩm nào được phê duyệt qua việc tạo cấu trúc này.
