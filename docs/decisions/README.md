# Quyết định kỹ thuật (ADR)

Mỗi quyết định quan trọng dùng file `NNNN-short-title.md`, ví dụ `0001-web-framework.md` sau khi thực sự lựa chọn công nghệ.

Nội dung gồm: trạng thái, ngày, bối cảnh, các phương án, quyết định, lý do và hệ quả. Quyết định bị thay thế vẫn được giữ lại và liên kết tới bản thay thế. Thư mục này hiện chưa ghi nhận quyết định công nghệ.
