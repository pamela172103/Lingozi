# Ứng dụng web Lingozi

Thư mục dành cho mã nguồn website sau khi lựa chọn công nghệ. Hiện chưa có ứng dụng, dependencies hoặc lệnh chạy/build/test.

Trước khi khởi tạo: chốt yêu cầu MVP, đánh giá framework và ghi quyết định tại `docs/decisions/`. Sau khi khởi tạo, cập nhật README này với phiên bản runtime, cách cài theo lockfile, biến môi trường, lệnh chạy và kiểm thử đã được xác minh. Unit/integration tests đặt theo quy ước của stack được chọn.
