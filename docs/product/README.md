# Tài liệu sản phẩm

Lưu tầm nhìn, đối tượng học, PRD toàn sản phẩm, phạm vi MVP và roadmap. Tên file gợi ý: `vision.md`, `prd.md`, `mvp-scope.md`, `roadmap.md`.

Bắt đầu bằng việc làm rõ người học mục tiêu, mục tiêu học tập và vấn đề cần giải quyết. Chưa mặc định cấp độ CEFR, mô hình thu phí hay tính năng AI.
