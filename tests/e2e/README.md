# Kiểm thử hành trình người dùng

Dành cho kiểm thử xuyên ứng dụng dựa trên acceptance criteria của tính năng. Hiện chưa có runner hoặc bài kiểm thử thực thi. Chọn công cụ và bổ sung lệnh chạy sau khi ứng dụng có hành trình thực tế. Dùng dữ liệu giả lập; không dùng tài khoản hoặc dữ liệu học viên thật.
